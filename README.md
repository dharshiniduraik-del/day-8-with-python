# day-8-with-python
## Project Overview

This project demonstrates the implementation of a *Decision Tree Classification algorithm* using Python and Machine Learning.

The project uses a heart disease dataset stored in decisiontree.csv. The dataset contains different patient-related features, and the target column is used to predict the presence or absence of heart disease.

A Decision Tree Classifier is trained using the dataset, predictions are generated, and the model performance is evaluated using training and testing accuracy.

The project also explores different tree depths to understand their effect on model performance.

---

## Objectives

The main objectives of this project are:

- To load and explore the heart disease dataset.
- To identify the input features and target variable.
- To divide the dataset into training and testing sets.
- To build a Decision Tree Classification model.
- To train the model using training data.
- To predict the target values for test data.
- To visualize the Decision Tree.
- To test different max_depth values.
- To calculate training and testing accuracy.
- To understand how Decision Trees can be used for classification.
